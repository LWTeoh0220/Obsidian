# Topic：行销与零售上的应用
## 行销理论 —— STP市场区隔理论
- Segmentation 市场区隔
	辨识消费者
		Identify Bases for Segmenting the Market
		Develop Profiles of Resuliting Segments —— Product（产品）、Price（价格）、Place（地点/通路）、Promotion（促销）
- Targeting 选择目标市场
	选择市场区隔
		Develop Selection Criteria
		Select Target Segment(s)
- Positioning 市场定位
	对每个目标市场建立定位并沟通
		Develop Positioning for Each Target Segment
		Develop Maketing Mix for Each Target Segment
