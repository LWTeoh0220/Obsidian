## 三反引号代码块
#### 公式 ` ``` 多行文字 ``` `

```Python showLineNumbers
x = 5
def ans(x):
	return [a for a in range(x)]
print(ans(x))

```

> 备注：
> 可以再前边的三反引号写**指定的程式语言**
