## 📌 定義與公式

a = `np.array([[1,2,3],[3,4,5]])`

### 建立阵列

| Code                           | 用途        | 备注                                       |
| ------------------------------ | --------- | ---------------------------------------- |
| `np.array([])`                 | 创建数组      |                                          |
| `np.zeros(1d,2d,3d)`           | 每个数值为0的阵列 | 多维，`np.zeros(4) -> array([0.,0.,0.,0.])` |
| `np.ones(1d,2d,3d)`            | 每个数值为1的阵列 | 多维，`np.ones(4) -> array([1.,1.,1.,1.])`  |
| `np.empty(1d,2d,3d)`           | 随机数字      | 多维，`np.zeros(4) -> array([.,.,.,.])`     |
| `np.tile([array],(shape))`<br> | 复制现有阵列多次  | 多维                                       |
| `np.eye(1d,2d,对角线起始点)`         | 对角线1，其余0  | 二维                                       |
| `np.arange(起始，终值, 间距)`         | 元素范围的数组   | 一维，`np.arange(0,10,5)`                   |
| `np.linspace(起始、终值，个体数)`       | 等差数值      | 一维                                       |
| `np.logspace(起始、终值，个体数)`       | 对数数值      | 一维                                       |

### 读取 迭代 赋值 阵列

| Code                    | 用途    | 备注                                                                                                                         |
| ----------------------- | ----- | -------------------------------------------------------------------------------------------------------------------------- |
| `name[]`                | 切片读取  | `a[0][1], b[:2][2]`                                                                                                        |
| `name[cond.]`           | 布林值读取 | `a[a>2], b[b[:]>3]` 多维阵列变成新的一维阵列                                                                                           |
|                         |       |                                                                                                                            |
| `np.nditer(name)`       | 迭代多维  | 用一次for loop去取多维的array资料 `for i in ...` <br>`np.nditer[a], np.nditer[a[...,::2]`<br>可设定参数 flags、op_flags、op_dtypes、order... |
| `np.ndenumerate(name)`  |       | `for i,j in np.ndenumerate(a):`                                                                                            |
|                         |       |                                                                                                                            |
| `name[][] / name[,]= x` | 赋值    | `a[0][0] = 1` 或 `a[0,0] = 1`<br>                                                                                           |
| `name[[]/:,[]/:] = x`   | 批次赋值  | `a[:,[1,2] = 3`                                                                                                            |
|                         |       |                                                                                                                            |
|                         |       |                                                                                                                            |
