## 1. 程式语言 (Programming Languages)

**代表：Java, C, Python, C++, Go**  
这类语言拥有「大脑」，负责处理**逻辑**、**运算**和**数据流动**。

- **本质**：包含变数、回圈 (Loop)、条件判断 (If-Else)。
- **用途**：编写演算法、开发作业系统 (C)、制作手机 App (Java)、或跑 AI 模型 (Python)。
- **关键点**：它们能「做决策」，告诉电脑如何一步步完成任务。

## 2. 标记与排版语言 (Markup & Typesetting Languages)

**代表：Markdown, LaTeX, HTML, XML**  
这类语言负责「外观」，用来描述**文档结构**和**视觉呈现**。

- **本质**：使用特定的符号（标签）来标记文字的属性。
    - **Markdown**：讲求「快速、易读」，用简单的 `#` 做标题，适合写笔记、写 README。
    - **LaTeX**：讲求「精准、专业」，适合排版复杂的学术论文、数学公式。
- **关键点**：它们本身没有逻辑，必须经过「渲染」或「编译」变成漂亮的 PDF 或网页。

## 3. 资料库查询语言 (Query Languages)

**代表：SQL (Structured Query Language)**  
这类语言是「翻译官」，专门负责**与资料库沟通**。

- **本质**：宣告式 (Declarative)。你只需要告诉电脑「我要找什么资料」，而不用教它「怎么翻遍硬碟去找」。
- **用途**：从庞大的资料库中筛选、新增、修改或删除资料。
- **关键点**：它不适合用来写独立程式，但在资工领域，它是处理后端资料的「标配」。


## 4. 样式语言 (Style Sheet Languages)

**代表：CSS (Cascading Style Sheets)**  
这类语言专门负责**「美化」**。

- **本质**：它通常依附在标记语言（如 HTML）之上，定义颜色、字型、间距和排版。
- **用途**：如果 HTML 是房子的结构，CSS 就是油漆、灯光和装潢。
- **关键点**：它不负责逻辑，也不负责内容，只负责「好看」。


## 5. 脚本语言 (Scripting Languages / Shell)

**代表：Bash, PowerShell**  
这类语言是**「指挥官」**。

- **本质**：直接在作业系统（Linux, Windows）上执行命令的工具。
- **用途**：用于自动化任务（如：每天凌晨两点自动备份资料、一键部署程式码到伺服器）。
- **关键点**：资工系学生必须学会 Bash，因为这是管理 Linux 服务器的母语。


## 6. 资料交换格式 (Data Serialization Languages)

**代表：JSON, YAML, XML**  
这类语言负责**「沟通」**，它们虽然叫语言，但更像是一种**格式标准**。

- **本质**：用来储存和传输资料，让人类和电脑都能看懂。
- **用途**：
    - **JSON**：网页前端与后端交换资料的标准（例如：Facebook 传回你的好友列表）。
    - **YAML**：常用于设定档（Configuration），例如设定你的开发环境。
- **关键点**：它们没有执行功能，纯粹是为了让资料在不同系统间传递时不产生乱码或误差。


## 7. 硬体描述语言 (Hardware Description Languages, HDL)

**代表：Verilog, VHDL**  
这类语言是**「电路图」**，是资工系偏向「硬体」课程的重点。

- **本质**：用来描述电子电路的结构和行为。
- **用途**：设计 CPU、制作显示卡晶片或是写 FPGA。
- **关键点**：它们长得像程式，但实际上是在「画电路」，不是在电脑上跑软体。
