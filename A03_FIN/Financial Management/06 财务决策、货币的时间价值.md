# Topic：财务决策、货币的时间价值




## 基本数学整理：

##### 有限等比级数：
$S_n = a + ar^1 + ar^2 +\dots + ar^n=\dfrac{a(1-r^n)}{1-r}, r\not= 1$


##### 无限等比级数：
$S_n = a + ar^1 + ar^2 +\dots + ar^n + \dots=\dfrac{a}{1-r}, |r|<1$
$\sum\limits_{n \to \infty}r^n=0,|r|<1$


##### 自然指数函数之底数(尤拉数，自然常数)
$e^1 =\lim\limits_{n \to \infty}(1+\frac{1}{n})^n =\lim\limits_{h \to 0}(1+h)^{\frac{1}{h}}$
(1+接近于零的无穷多次方为e)


## 货币的时间价值

0     1     2     3     4     5  $\uparrow$ x （流入）
——————————
$\downarrow$ -x （流出）

- 第一期的期末为第二期的期初
- 线往下箭头为流出，线网上箭头为流入


$FV$：终值
$PV$：现值
$r$：利率
$t$：期数

$(1+r)^t$：终值的利率因子

#### 终值 FV  —— Future Value
Compound interest——复利：
$FV_t = PV\times (1+r)^t$


#### 现值 PV —— Present Value
Compound interest——复利：
$PV_t = \dfrac{FV}{(1+r)^t}$





单利simple interest 
$FV = P(1 +r\times n)$
 $FV$为终值，$P$为本金，$r$为利率，$n$为计息期数
 
定期复利 periodic compounding interest 


连续复利 continuous compounding interest

## （银行提供）贷款形式与贷款的摊销
纯折价贷款
纯付息贷款
**分期偿还贷款**

### 1. 纯折价贷款 (pure discount loan)
$$FV = PV\times(1 +r)^n$$

偿还价必然高于支付价
#### a) 国库券（Treasure Bill,T-Bill(TB1))
- 融资短期资金，国库券到期一次偿还本息
- TB1甲种国库券、TB2乙种国库券——公开市场操作

### 2. 纯付息贷款 (interest-only loan)
- 每期只偿付利息，到期时清偿最后一次利息+本金


## 3. 分期偿还贷款(amortized loan)
### 两类型
#### 第一型 
指期借款人初借入一筆款項，其間每期期末除付息外並**固定額償付本金欠款**。

每期支付本金+该期利息


#### 第二型
指期借款人初借入一筆款項，其間每期期末償付一筆固定金額，這筆固定金額中包括**本金及利息**，到償付**最後一筆固定金額時會正好還完所有本息**。

每期偿还金额： 定期偿付- 利息费用



成長型的普通年金現值 的 成长率不能大于年利率
