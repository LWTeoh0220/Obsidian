# Topic：公理与条件机率

## 2.1 机率公理性质 Axioms of Probability
- 公理是数学理论的基石
- 公理不可被证明
- 公理是基本的性质

1. 对任何事件A而言，P(A) $\ge$ 0
	
2. P(S) = 1
	样本空间，所有元素的集合必然为1
3. 事件$A_1,A_2,......$互斥 $\Rightarrow$ P($A_1\cup A_2\cup A_3 \dots$) = P($A_1$) + P($A_2$) + P($A_3$)
	所有事件若互斥为各自机率的相加

### 延伸性质
1. 若 E = {$o_1,o_2,...,o_n$}
则$P（E） = P({o_1}) +... P(o_n)$

2. $P(\phi) = 0$
S$\cap \phi =\phi \Rightarrow S,\phi 互斥$
$\Rightarrow P(S) = P(S\cup \phi) = P(S) + P(\phi)$


3. P(A) = 1 - P($A^C$) 
$\Rightarrow$ A $\cap$ $A^C$ = $\emptyset,加以S = A \cup A^c$ 
$\Rightarrow$ A, $A^C$ 互斥  —— 公理三


4. P(A) = P(A-B) + P(A $\cap$ B)
$\Rightarrow$ P(A-B) $\cap$ P(A $\cap$ B) = $\emptyset$
$\Rightarrow$ A = (A-B) $\cup$ (A $\cap$ B)   —— 公理三


5.  P(A $\cup$ B) = P(A) + P(B) - p(A $\cap$ B)
$P(A \cup B) = (P(A-B) )+() P(A \cap B) + P(B-A))$
		$= P(A) - P(A \cap B)+ P(B)$


6. $C_1$, $C_2$ $\dots$ , $C_n$ 互斥 且 $C_1 \cup C_2 \cup \dots \cup C_n = S$
则对任何事件 $A$ : P(A) = P($A \cap C_1$) + P($A \cap C_2$) + $\dots$  + P($A \cap C_n$)
$P(笑) = P(笑\cap早) +P(笑\cap午)+P(笑\cap晚)$

7. $若A\subset B，则P(A)<P(B)$


8. Boole's 不等式
$对任意n个事件A_1,A_2,...,A_n而言，$
$P(\bigcup_{i=1}^n A_1)\le \sum_{i=1}^n P(A_i)$


9. Bonferroni's 不等式
$对任意n个事件A_1,A_2,...,A_n而言，$
$P(\bigcap_{i=1}^n A_1)\ge 1-\sum_{i=1}^n P(A_i^c)$




## 2.2 条件机率


P($X | Y$  )  —— P of X given Y
$X$：所关心之事件
$Y$  : 条件（观察到的，已发生的事件）

若某实验结果$o_i$ 与某条件$Y$ 不相交，则
P($o_i$ | $Y$ ) = 0


P($o_i | Y$) = $\frac{P(o_i)}{P(o_i) + P(o_2) + \dots + P(o_n)}$ = $\frac{P(o_i)}{P(Y)}$

考虑事件 X = {$o_1,o_2,q_1,q_2$}，已知事件Y = {$o_1,o_2,o_3$}发生，则
P(X|Y) = P($o_1 | Y$) + P($o_2 | Y$) = $\frac{P(o_1)}{P(Y)}$ + $\frac{P(o_2)}{P(Y)}$ = $\frac{P({o_1,o_2})}{P(Y)}$ = $\frac{P(X \cap Y)}{P(Y)}$



#### P($X|Y$) = $\dfrac{P(X \cap Y)}{P(Y)}$ 

>key words:
 "condition on", "Suppose", "if", "Assuming", "given that"


#### 条件机率 性质
1. 性质一 ： P(X|Y) = $\frac{P(X \cap Y) \ge 0}{P(Y) \ge 0}$ $\ge 0$
2. 性质二： P(Y|Y) = $\frac{P(Y \cap Y)}{P(Y)}$ = 1
3. 性质三： A，B互斥，则P($A \cup B|Y$) = $\frac{P(A)}{P(Y)} + \frac{P(B)}{P(Y)}$ = P(A|Y) + P(B|Y)

### Total Probability 定理

P(A) = P(A|$C_1$)P($C_1$) + P(A|$C_2$)P($C_2$) + $\dots$  + P(A|$C_n$)P($C_n$)
    =$P(A \cap C_1) + P(A \cap C_2) + \dots + P(A \cap C_n)$

P(A|$C_1$)P($C_1$) = $\dfrac{P(A \cap C_1)}{P(C_1)} * P(C_1)$

## 贝氏定理 Bayes‘ Rule
$C_1$, $C_2$ $\dots$ , $C_n$ 互斥 且 $C_1 \cup C_2 \cup \dots \cup C_n = S$
则对任何事件 $A$

P($C_j|A$) = $\dfrac{P(C_j \cap A)}{P(A)}$ 
    = $\dfrac{P(A|C_j)(C_j)}{P(A|C_1)P(C_1) + P(A|C_2)P(C_2) + \dots  + P(A|C_n)P(C_n)}$
